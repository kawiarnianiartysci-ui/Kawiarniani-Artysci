## 🖥️ Jak otworzyć w Excelu?

### **Opcja 1: Podwójne kliknięcie (najprostsze)**
```
1. Otwórz File Explorer
2. Przejdź do folderu
3. Dwuklik na DOKUMENTACJA_KAWIARNIANI_BACKUP.csv
4. Excel otworzy i poprosi o format
5. Wybierz: "Dalej" → UTF-8 → "OK"
6. GOTOWE!
```

### **Opcja 2: Otwórz przez Excel (jeśli Option 1 nie działa)**
```
1. Otwórz Excel
2. File → Open
3. Przejdź do folderu
4. Zaznacz DOKUMENTACJA_KAWIARNIANI_BACKUP.csv
5. Pojawi się dialog "Text Import Wizard"
6. Separator: Comma (,) → Dalej
7. Encoding: UTF-8 → OK
8. GOTOWE!
```

### **Opcja 3: Bez separatora (jeśli chcesz czytelniejszy podgląd)**
```
1. Skopiuj zawartość pliku
2. Otwórz Excel
3. Ctrl+V (Paste)
4. Data → Text to Columns
5. Delimiter: Comma → Finish
6. Teraz wszystko jest w osobnych kolumnach
```

## 🔄 Co jeśli coś nie załaduje się dobrze?

**Problem: Tekst jest w jednej kolumnie (nie podzielony)**
- Rozwiązanie: Zaznacz kolumnę A → Data → Text to Columns → Delimiter: Comma

**Problem: Znaki diakrytyczne pokazują się źle (Polska znaki)**
- Rozwiązanie: W Import dialog wybierz "UTF-8" encoding

**Problem: Komórki są za wąskie**
- Rozwiązanie: Select all (Ctrl+A) → Format → Column Width → Auto (40-50)
